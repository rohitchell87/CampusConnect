# CampusConnect Frontend

This frontend is built with Vite, React, TailwindCSS, React Router, and Axios.

## Setup

Install dependencies:

```bash
cd frontend
npm install
```

Run development server:

```bash
npm run dev
```

## Notes

- API integration is prepared for the backend at `http://localhost:8080`.
- Authentication flows are scaffolded, but the login/register UI does not yet persist JWT tokens.
